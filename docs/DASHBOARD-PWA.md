# Dashboard PWA

`/admin` now links a dedicated manifest with stable id/start_url/scope `/admin`, standalone display and 192/512 icons. The public website's browser-display manifest is unchanged. HTTPS production is required for installation. Android browsers may provide an install event; the button only appears when that actual event exists. iOS Safari instead gets explicit Share → Add to Home Screen guidance. Installed mode hides installation controls. No promise that all browsers offer installation.

Service worker `/admin/sw.js` uses scope `/admin` and caches only the generic `/admin/offline.html` document. It does not cache authenticated HTML, API responses, RSC data, media, passwords, edits or inquiries. All admin navigation is network-only with a generic offline fallback. API mutations are never intercepted or queued; editing/saving requires internet. Offline indicator warns not to abandon unsaved changes. Old worker-owned offline caches are deleted during activation. No global cache purge.

Authentication is unchanged and fails closed until owner sets ADMIN_PASSWORD_HASH. Never create a default password, expose a setup/password form without ownership verification, or put credentials in source. Owner should choose a NEW password after any value shared in chat, generate the salted hash locally with `npm run admin:hash`, and paste it directly into the Vercel environment-variable Secret for Production/Preview themselves. Never send password/hash in chat. Redeploy after setting it. Install does not bypass login; sessions expire in 24 hours. Logout clears the existing cookie then reloads `/admin`, not marketing landing.

After activation, owner acceptance test on real phone: login → Programs → edit price → Preview → Save → confirm public price; add program as Draft → fill materials/duration → publish when ready; upload photo; verify inquiry status; logout → login screen. Use safe test content on preview, not real production data. No coding is needed for these CMS operations once login setup is completed. Installation via physical Android/iPhone and authenticated flows remain owner acceptance tasks if credentials are not configured.

## App icon update v2

Shinta Admin now uses `sk-admin-v2-192.png` and `sk-admin-v2-512.png`, with a dedicated 180px Apple touch icon. Original freestanding SK is rendered ivory on charcoal. Full opaque square backgrounds allow platform masking; glyph stays in central 68% for rounded/circular crops. Manifest id/start_url remain unchanged, and browser favicons/public website manifest are untouched. New filenames avoid stale image URL caches. Already-installed app icons may update later according to OS/browser; if they remain old, remove the home-screen shortcut and reinstall from `/admin` (ensure unsaved edits are saved first). No reset of server-side content or login configuration is needed.

## Mobile dashboard redesign

Bottom navigation: Beranda, Program, Inquiry, Lainnya. Lainnya includes profile, gallery, testimonials, FAQ, preview, public-site link and logout. Desktop sidebar remains. Fixed save bar sits above bottom navigation with safe-area padding; all edits remain explicit saves and version checked. Refresh/close warns about unsaved changes. Program search/status filtering and a four-part editor (Info kelas, Materi, Harga, Foto) replace long accordion forms; new programs are drafts. Price/publication changes remain local until saved. Inquiry status changes are immediate, with safe WhatsApp contact and status filtering. Overview inquiry count is shown as unknown until loaded and labelled as loaded records, not an invented global total.

`/admin/design-demo` is available ONLY on preview deployments, with hardcoded public seed content. It is NOT an auth bypass: no session, private storage read, API access or upload. Demo saves never write; inquiry list is empty and does not call API; upload input is disabled. Production returns 404. It is for visual/interactivity review, not proof that real authenticated writes work. Admin APIs remain protected. Manual acceptance on owner's authenticated phone remains necessary.
